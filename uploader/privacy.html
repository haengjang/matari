1. 적용 범위와 운영자

이 방침은 GitHub 계정 haengjang이 matari 저장소에서 제공하는 l2k uploader 소개 웹사이트와 로컬 데스크톱 업로더에 적용됩니다.

2. 현재 웹사이트에서 처리하는 정보

이 웹사이트는 정적 소개 페이지이며 회원가입, 로그인, 입력 양식 또는 파일 업로드 기능이 없습니다. 운영자는 이 페이지를 통해 TikTok 계정 정보, 액세스 토큰, 영상 또는 결제 정보를 수집하지 않습니다. 자체 분석 스크립트, 광고 추적 도구, 쿠키 및 브라우저 저장소를 사용하지 않습니다.

3. 호스팅 제공자의 정보 처리

웹사이트는 GitHub Pages에서 제공됩니다. GitHub는 호스팅과 보안 등을 위해 IP 주소와 요청 기록 등 접속 관련 정보를 처리할 수 있습니다. 해당 처리와 보관에는 GitHub 개인정보처리방침이 적용됩니다.

4. 문의 시 제공하는 정보

GitHub Issues를 통해 문의하면 GitHub 사용자명과 문의 내용이 공개될 수 있습니다. 문의 내용은 문의 대응에 사용됩니다. 공개 문의에 비밀번호, 액세스 토큰, 연락처 등 민감한 정보를 포함하지 마세요. 게시 내용의 수정·삭제는 GitHub 기능을 사용하거나 운영자에게 요청할 수 있습니다. GitHub 자체 보관 기록은 GitHub 정책에 따릅니다.

5. 보관·제공 및 권리 행사

현재 운영자가 이 소개 페이지에서 직접 수집해 별도 보관하는 방문자 개인정보는 없습니다. 문의에 포함한 정보의 열람·정정·삭제 요청은 저장소 문의 페이지로 접수할 수 있습니다. 요청에는 민감한 정보를 공개하지 말고 대상 문의의 링크만 적어 주세요. 호스팅 접속 정보에 대한 요청은 GitHub의 개인정보 문의 절차를 이용해야 합니다.

6. TikTok 연동 및 로컬 앱

로컬 업로더는 사용자가 로그인하고 승인한 TikTok 계정의 표시 이름, 게시 허용 설정, OAuth 액세스·갱신 토큰을 처리합니다. 선택한 영상, 설명, 공개 범위, 댓글·듀엣·이어붙이기 설정, 상업성 및 AI 생성 표시를 사용자의 게시 동의 후 TikTok API에 전송합니다. TikTok에는 해당 서비스의 개인정보처리방침이 적용됩니다.

개발자 인증정보, 계정 토큰과 영상 데이터는 이 PC에서 실행되는 앱의 메모리에서만 처리하며 운영자 서버나 별도 파일에 저장하지 않습니다. 종료 시 연결 정보가 사라지고 다음 실행 때 다시 연결해야 합니다. 로그인 보호용 쿠키는 로컬 주소에서만 사용하며 추적에 사용하지 않습니다.

앱의 ‘연결 해제’ 또는 TikTok 설정의 앱·서비스 권한 메뉴에서 권한을 철회할 수 있습니다. 이미 게시한 영상은 앱 종료나 연결 해제로 삭제되지 않으며 TikTok에서 직접 관리·삭제해야 합니다. 공개 GitHub 문의에는 영상, 비밀키나 토큰을 포함하지 마세요.
